# Kereos V9

Futuristic static crypto trading demo.

- Live CoinGecko prices with fallback prices
- Major + meme coins
- Interactive canvas charts
- BUY / SELL execution
- 10/25/50/75/100% position selling
- Trade markers on charts
- Persistent cash, holdings, P&L and history via localStorage
- Responsive mobile layout
- Animated/glowing futuristic UI
